# 2026-09-07 工作日志

## CoordEngine 模拟模式
- CoordEngine 新增 `m_simMode`(默认 true) + `m_simSegmentMs`(默认 300ms) + `setSimMode()`/`setSimSegmentMs()`
- `start()`/`onPoll()`/`stop()` 三分支支持模拟模式：模拟时不调 CoordMgr，用 pollTimer 定时逐段推进
- 模拟模式下：start → segmentStarted(0) → 每 300ms 一段 segmentDone + 下一段 segmentStarted → allDone
- 目的：无硬件时跑通插补状态机，验证 UI 红/绿/蓝变色逻辑

## 待办

- 插补模式：动态(逐段) vs 静态(一次全塞) 待定

## CoordMode 枚举 + 配置 UI
- ControllerData.h：`enum class CoordMode { Static=0, Dynamic=1 }` + `CoordCfg { mode=Dynamic, enableSim=true }`
- GtsMgr：新增 `m_coordCfg` 成员 + `coordCfg()` 访问器 + `applyCoordCfg()`(同步 enableSim 到引擎 setSimMode)
- ConfigWidget：comboBox_coordMode(静态/动态) + checkBox_coordSim(模拟/实际)，refreshCoordCfg/commitCoordCfg 读写
- 注：CoordMode 静态模式引擎侧尚未实现，目前仅存储配置，引擎只跑动态模式

## CoordCfg 持久化到 gtsConfig.json
- GtsConfigMgr::saveAxisConfig：root 加 `coord` 字段 `{ mode, enableSim }`
- GtsConfigMgr::loadAxisConfig：读取 `coord` 字段写回 coordCfg + 调 applyCoordCfg 同步引擎
- JSON 结构：`{ version, axisCount, cardMode, coord: {mode, enableSim}, axes: [...] }`

## 引擎执行分支改为读配置(单一数据源)
- CoordEngine 去掉 m_simMode 副本，改为持有 `CoordCfg* m_coordCfg` 指针
- `sim()` 私有方法直接读 `m_coordCfg->enableSim`，start/onPoll/stop 三处用 sim() 分支
- setSimMode/simMode 替换为 setCoordCfg(CoordCfg*) + simMode()(实现移到 cpp)
- GtsMgr 构造时 `setCoordCfg(&m_coordCfg)`，applyCoordCfg 变空(引擎直接读配置，无需同步)
- CoordEngine.cpp 需 include ControllerData.h(访问 CoordCfg::enableSim)

## 插补静态模式实现
- CoordEngine 加 `staticMode()`(读 coordCfg->mode == Static)
- executeSegment 改返回 bool，去掉内部 emit segmentStarted(改由 start/onPoll 统一发)
- start 静态模式：循环塞满全部段 → start 一次 → emit started + segmentStarted(0)
- onPoll 静态模式：getRemainingSegment 反推 completed = N - remain，while 循环发 segmentDone + 下一段 segmentStarted，全完成发 allDone
- 动态模式 onPoll：executeSegment 后补 emit segmentStarted(当前段)
- 注意：静态/动态真实硬件语义(remain off-by-one)需接卡后校准
