# 2026-09-07 工作日志

## CoordEngine 模拟模式
- CoordEngine 新增 `m_simMode`(默认 true) + `m_simSegmentMs`(默认 300ms) + `setSimMode()`/`setSimSegmentMs()`
- `start()`/`onPoll()`/`stop()` 三分支支持模拟模式：模拟时不调 CoordMgr，用 pollTimer 定时逐段推进
- 模拟模式下：start → segmentStarted(0) → 每 300ms 一段 segmentDone + 下一段 segmentStarted → allDone
- 目的：无硬件时跑通插补状态机，验证 UI 红/绿/蓝变色逻辑
