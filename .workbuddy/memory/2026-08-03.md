# 2026-08-03

## GTSSimpleController Widget 批量命名重构

用户已将 GtsCore 中各类 mgr 和数据结构命名做了修改 (参考 IOWidget 的改法), 需要批量更新 GTSSimpleController/Widget 下所有引用旧命名的文件。

### 变更内容

1. **管理器类名**: `CTotalMgr` -> `GtsMgr`
2. **Include 路径**: `"../Mgr/XxxMgr.h"` -> `"../../GtsCore/GtsXxxMgr.h"`
3. **数据结构名**: `stuClock`->`Clock`, `stuAxis`->`SingleAxisInfo`, `stuJogParam`->`JogParam`
4. **字段名**: `bServoOn`->`isServoOn` 等 b 前缀改 is 前缀; `dEncPosMm`->`encPosMm` 等 d 前缀去掉; `lPrfMode`->`prfMode`; `dMotionVel`->`motionVel`; `Delay`->`delay`
5. **信号名**: `CTotalMgr::logUpdated` -> `GtsMgr::logMessage`
6. **enum**: `homeMode` (小写) -> `HomeMode` (enum class)
7. **结构修复**: `SingleAxisInfo` 不再包含 `trapParam`/`jogParam`, 这些移到了 `SingleAxisConfig` (通过 `m_pTotalMgr->axisCfg()->axes[index]` 访问)

### 修改文件清单 (9 个文件)
- BoardWidget.h / .cpp
- AxisWidget.h / .cpp (最复杂, trap/jog 参数读写全改走 axisCfg())
- MasterControlWidget.h / .cpp
- ConfigWidget.h / .cpp
- GTSControllerWidget.cpp

### 验证
grep 确认 Widget 目录下无残留旧命名: CTotalMgr, stuAxis, stuClock, stuJogParam, logUpdated, old field names, old include paths, static_cast<homeMode> 全部为 0 匹配。
