## 编码问题修复

### 问题
批量修改后 MasterControlWidget.cpp 出现 C2001/C2027 编译错误。根因: Edit 工具把 GBK 文件转成了 UTF-8 无 BOM, MSVC 按 GBK 解读导致中文乱码。

### 修复
1. MasterControlWidget.cpp: 从 git 恢复 10 处乱码中文 (U+FFFD), 加 UTF-8 BOM
2. AxisWidget.cpp / BoardWidget.cpp / MasterControlWidget.h: GBK -> UTF-8+BOM (ASCII 部分未损坏, 只需转码)
3. BoardWidget.h: 补 UTF-8 BOM

### 教训
- 项目 .vcxproj 无 /utf-8 编译选项, MSVC 对无 BOM 文件按系统区域编码 (GBK) 解读
- **安全编码: 所有含中文的源文件必须是 UTF-8+BOM 或 GBK, 不能是 UTF-8 无 BOM**
- Edit 工具修改 GBK 文件时会转为 UTF-8 无 BOM, 需手动补 BOM 或用 Python 操作

## bug fix: loadConfigFile 覆盖轴名称

**根因**: ConfigMgr::readAllAxisConfigFromBoard() 先 `m_axisCfg->axes.resize(count)` 重建所有轴配置 (name 重置为默认 X), 然后 loadConfigFile() 紧接着 saveAxisConfig() 覆盖 JSON。轴名称是纯软件概念，硬件读不回。

**修复**: GtsConfigMgr.cpp line 256, `resize(count)` → `if (size < count) resize(count)`, 仅扩容不重建，保留 JSON 加载的软件端字段 (name/ctrlMode/homeConfig/axisLimit/softPulseScale)。

## bug fix: ConfigWidget 界面初始值不刷新 (轴名显示错误)

**根因**: GTSControllerWidget::Init() 中 loadAxisConfig() → emit configChanged() 先于 ConfigWidget 的 initUI() 执行。onConfigChanged 触发时 comboBox 为空，刷新无效。initUI 之后没有重新刷新 UI。

**修复**: ConfigWidget.cpp 构造函数 QTimer 回调末尾加上 `onConfigChanged()`, UI 就绪后做一次初始刷新。
