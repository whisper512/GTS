## 编码问题修复

### 问题
批量修改后 MasterControlWidget.cpp 出现 C2001/C2027 编译错误。根因: Edit 工具把 GBK 文件转成了 UTF-8 无 BOM, MSVC 按 GBK 解读导致中文乱码。

### 修复
1. MasterControlWidget.cpp: 从 git 恢复 10 处乱码中文 (U+FFFD), 加 UTF-8 BOM
2. AxisWidget.cpp / BoardWidget.cpp / MasterControlWidget.h: GBK -> UTF-8+BOM (ASCII 部分未损坏, 只需转码)
3. BoardWidget.h: 补 UTF-8 BOM

### 教训
- 项目 .vcxproj 无 /utf-8 编译选项, MSVC 对无 BOM 文件按系统区域编码 (GBK) 解读
- **安全编码: 所有含中文的源文件必须是 UTF-8+BOM 或 GBK, 不能是 UTF-8 无 BOM**
- Edit 工具修改 GBK 文件时会转为 UTF-8 无 BOM, 需手动补 BOM 或用 Python 操作

参考 D:\QT_PRJ\EzcadDevelopment 项目的 AxisControlWidget 实现, 重构了 Gts400 的 AxisWidget。

4. 不改 UI 控件名 (保留 spinBox_trapMotionVel 等现有命名)
